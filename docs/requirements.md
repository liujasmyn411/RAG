# 沃林学生管理系统需求文档

## 1. 项目概述
本项目旨在开发一个基于FastAPI的学生管理系统，提供学生基本信息管理、考核成绩管理和就业管理三大核心功能模块。系统将采用RESTful API设计，支持前后端分离架构。

## 2. 功能需求

### 2.1 学生基本信息管理模块
- 学生信息增改查
- 创建新学生记录：学生编号、学生班级、学生姓名、籍贯、毕业院校、专业、入学时间、毕业时间、学历、顾问编号、年龄、性别
- 查询学生信息：支持按编号、姓名、班级等条件筛选
- 更新学生信息
- 逻辑删除学生

### 2.2 学生考核成绩管理模块
- 成绩录入与管理
- 按考核序次录入考核成绩：学生编号、考核序次、成绩
- 成绩修改与删除

### 2.3 学生就业管理模块
- 就业信息管理
- 记录学生就业状态：学生编号、学生姓名、学生班级、就业开放时间、offer下发时间、就业公司名称、就业薪资
- 按照学生编号、公司名字、工资范围查询学生就业信息
- 修改和删除学生就业信息
- 学生姓名（冗余）、学生班级（冗余）属于冗余字段，可自行设计表结构

### 2.4 班级管理模块
- 班级信息管理：班级编号、开课时间、班主任、授课老师等信息

### 2.5 老师管理模块
- 老师信息管理：老师信息、带班信息等

### 2.6 统计分析模块
#### 2.6.1 基本信息统计
- 查询所有超过30岁的学员的信息
- 统计每个班级的人数以及男生女生的人数

#### 2.6.2 成绩统计
- 查询每次考试成绩都在80分以上的学生的编号、姓名和成绩
- 查询有两次以上不及格的学生的姓名、班级和不及格成绩
- 统计每次考试每个班级的平均分，按照从高到低排序

#### 2.6.3 就业统计
- 统计就业薪资最高的前五名学生的姓名、班级、就业时间、就业公司
- 统计每个学生的就业时长（offer下发时间 - 就业开放时间）
- 统计每个班级的平均就业时长（只统计进入就业阶段的学生，即有就业开放时间）

## 3. 非功能需求

### 3.1 技术栈
- 后端框架：FastAPI
- 数据库：MySQL
- 数据验证：Pydantic
- 文档：提供完整的API文档（Swagger）

## 4. API设计概要
系统接口要遵从Restful规范，并且考虑前端便利性、用户体验及效率。

### 4.1 学生基本信息端点
- `GET /students`：获取学生列表
- `POST /students`：创建新学生
- `GET /students/{id}`：获取特定学生信息
- `PUT /students/{id}`：更新学生信息

### 4.2 成绩管理端点
- `GET /score/{stu_id}`：获取学生成绩
- `POST /score/`：录入成绩
- `PUT /score/update`：修改指定学生的某次成绩
- `POST /score/delete`：删除指定学生的某次成绩

### 4.3 就业管理端点
- `GET /employment/students/{id}`：获取学生就业信息
- `GET /employment/class/{id}`：获取班级学生就业信息
- `POST /employment/students/{id}`：添加/更新就业信息

### 4.4 统计分析模块端点
- 路径前缀：`/statistics`（后续自定义）

### 4.5 其它模块端点
- 自定义设计

## 暂时想到的功能
### 学业辅导与诊断
1. 错题根因分析
实现路径：将学生的错题和对应的教材知识点文档存入向量库。RAG 检索该题对应的知识点讲解，LLM 对比错误步骤，用通俗语言指出是概念混淆还是计算失误。
2. 知识点答疑助手
实现路径：上传课程PPT、教科书、参考书构建知识库。学生提问时，RAG 精准定位相关段落，LLM 提取信息并生成拟人化的解答，避免幻觉。
3. 论文/作文智能初评
实现路径：将优秀的范文库和评分标准文档作为 RAG 底座。LLM 读取学生提交的文本，对照标准找出逻辑漏洞或语法错误，并给出修改建议。

### 行政与教务办公
1. 公告智能润色与生成
实现路径：录入学校过往的优秀公文和历史通知作为 RAG 语料。用户输入草稿，LLM 参考历史文风进行扩写、缩写或语气调整（如转为紧急通知）。
2. 制度文件速查
实现路径：将繁杂的校规、奖助贷政策、请假流程整理成文档库。老师或学生提问时，RAG 定位具体条款，LLM 提炼核心要点并以一问一答形式输出。
3. 会议纪要自动总结
实现路径：导入教务会议的录音转录文本。LLM 自动提取决议事项、待办任务（Action Items）和责任人，生成结构化的 Markdown 纪要。

### 家校沟通与心理
1. 家长话术生成器
实现路径：建立“沟通话术库”（如：如何委婉告知家长成绩下滑）。班主任输入学生情况，RAG 检索类似案例的话术，LLM 生成得体的沟通文案。
2. 心理访谈摘要
实现路径：将心理咨询记录（脱敏后）作为 RAG 参考。咨询师输入访谈录音稿，LLM 自动归纳学生的情绪波动周期和风险等级，辅助判断干预策略。
3. 评语自动生成
实现路径：录入往届优秀班主任的期末评语作为范例库。输入学生的性格特点和成绩表现，RAG 匹配相似学生的评语风格，LLM 生成个性化期末评语。

### 实用工具
1. 试题解析生成
实现路径：将题库和详细解析存入向量库。教师上传新试卷图片（OCR转文字后），RAG 匹配同类题型解法，LLM 批量生成标准化的答案解析步骤。
