# 记忆框架方案 — 章节摘要与关系

## 各章内容

**第 1 章 · 项目定位** — 画系统边界：四个外部角色（学生/辅导员/班主任/教务系统）、LangGraph 编排层 + 三数据库存储层的宏观拓扑，以及铁律"事实准确性 > 人格一致性"。

**第 2 章 · 工作记忆** — 定义 Agent 在**单次会话中的运行时状态**。核心是四层 State 结构（L0 安全熔断 > L1 事实锚点 > L2 对话流 > L3 人设增强包，优先级递减），以及消息构建时"事实注入在人格 Prompt 之后"的机制确保事实不可被篡改。展开三类安全事件（心理危机/内容安全/注入攻击）的两级检测和分级处理、会话关闭归档与跨会话 State 继承（full/partial/minimal 三级携带）、以及学生-教师-管理员的三层权限体系。

**第 3 章 · 长期记忆** — 定义**跨会话持久化的四层金字塔**：L0 角色本体（Neo4j，红楼人物+关系+名场面）、L1 业务事实（PG，成绩/学籍/考勤）、L2 语义认知（Neo4j，从 L3 提炼出的学生抽象特质）、L3 情景快照（Milvus Hot 存结构化摘要 + PG Cold 存原始对话全文）。重点展开 L3 双层存储的 Hot/Cold 架构和 L3→L2 提炼闭环。

**第 4 章 · L2 更新策略** — 决定 **"什么时候把碎片记忆提炼为抽象认知"**。门槛触发公式：未处理 L3 ≥ 5 条 OR 距上次 Reflection > 7 天 OR 心理危机立即触发。对比了每次触发/批量触发/门槛触发三种策略后选门槛触发，并给出 Reflection 节点的 6 步数据流。

**第 5 章 · 遗忘机制** — 定义**记忆如何随时间衰减**。双轨设计：软遗忘（指数衰减公式，不同重要性不同 λ — 危机永不衰减/情绪 λ=0.01/闲聊 λ=0.02/教务 λ=0.05）和硬遗忘（容量超限时驱逐最低分记忆）。同时覆盖 Neo4j 中黛玉→学生的"关心"关系边衰减。

**第 6 章 · 置信度体系** — 定义**"系统对自己的记忆有多确信"**的三层闭环：写入置信度（S/A/B/C/D 五级来源赋初始分）→ 检索置信度（ANN 粗排 + Reranker 精排 + 三档分拣）→ 一致性置信度（贝叶斯连续更新）。在此基础上扩展三个动力学机制——抗扰动（高置信度不易被弱证据动摇）、连续性惩罚（连续同向证据获得递增乘数）、长默回升（冲突长期未再出现时部分恢复但有永久疤痕）。

**第 7 章 · 冲突分类** — 定义**新旧认知出现矛盾时的六种处理方式**。通过决策树（情感极性→时间序列→来源层级→情绪/稳定）分流：类型一直接对立走完整贝叶斯对抗、类型二时间覆盖直接归档旧值、类型三范围细化并存升权、类型四来源冲突并存标注、类型五情绪波动不处理攒够提炼元认知、类型六语义重叠合并升权。

**第 8 章 · 架构全貌** — **工程实现蓝图**。包含系统总图、三种 intent 的数据流路由、LangGraph 节点图（含安全过滤前置节点）、检索增强的 Phase 1→2→3 混合编排策略、Milvus 两个 Collection 的 Schema 与分区设计、Neo4j 完整图模型（节点/关系/置信度字段/Cypher 查询）、以及 Reflection 节点的六步流程和 Prompt 设计。

## 章节关系

```
第1章 项目定位（原则与边界）
  │
  ├──→ 第2章 工作记忆（运行时状态）
  │      │  消费第3章的存储层来构建 State
  │      │  第2章的 L0~L3 State 映射到第3章的 L0~L3 存储
  │      │  第2章的安全熔断为整个系统提供前置保护
  │      │
  │      └──→ 第8章（编排层实现，将 State 流转落地为 LangGraph 节点）
  │
  ├──→ 第3章 长期记忆（持久化存储）
  │      │  定义 WHAT：存什么、存在哪、怎么存
  │      │
  │      ├──→ 第4章（定义 WHEN：L3 攒够了触发 Reflection 提炼为 L2）
  │      ├──→ 第5章（作用在第3章的 L3 和关系边上，控制"怎么忘"）
  │      └──→ 第8章（存储层实现，Schema 落地）
  │
  ├──→ 第6章 置信度体系（数学骨架）
  │      │  定义 HOW SURE：三层分值贯穿记忆的写入→检索→冲突全生命周期
  │      │
  │      ├──→ 第7章（第7章的类型一直接使用第6章的完整公式）
  │      ├──→ 第4章（Reflection 产出 C 级置信度，更新走第6章公式）
  │      └──→ 第8章（Reranker 检索实现 + Neo4j 置信度字段）
  │
  └──→ 第7章 冲突分类（裁决规则）
         │  定义 WHAT IF：新旧认知矛盾时的分流处理
         │
         └──→ 第4章（Reflection Step 4 调用冲突分类）
```

## 一句话总结

**第1章定原则 → 第3章定存储 → 第2章定运行时如何使用存储 → 第4章定时从 L3 提炼 L2 → 第7章处理提炼中的新旧冲突 → 第6章为全流程提供置信度计算 → 第5章让所有数据随时间衰减 → 第8章把这些整合为可执行的工程方案。**
